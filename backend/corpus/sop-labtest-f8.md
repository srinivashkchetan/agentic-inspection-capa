---
id: SOP-LABTEST-F8
title: Program compliance — valid lab test report (fail code F8)
---
Fail code F8 indicates no valid lab test report on file for the style. This is a
program/compliance gap handled by the rules track, not a workmanship corrective
action: obtain a current, in-scope lab report from an approved lab covering the
shipped style before release. Confirm the report number, date, and scope match
the purchase order and market requirements.
